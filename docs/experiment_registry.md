# ST3 experiment registry

[Current Project State](project_state.md) · [EXP-001–016 history and release](competition_release.md) · [Earlier research ledger][archive]

Scores are Contrast / Macro Log Loss in bits unless named otherwise. P2 figures are pooled held-out predictions from five painting-grouped folds unless the row specifies a single fold, pilot or diagnostic. Test-like P2 excludes English, Arabic and Chinese and rechecks scoring eligibility. Neither version of P2 is an independent test. Hosted Development results are listed separately on [Project State](project_state.md#hosted-development).

Commit IDs identify executed source when the run receipt establishes it. Where separate, the report or closure commit is also listed. Paths under `runs/` refer to ignored artifacts in the project workspace. Reports for unpublished branches are identified by their exact Git revision and path, readable with `git show <revision>:<path>` where those local refs exist. The public branch links below refer to existing historical records.

No EXP-034 run or implementation commit was found. |

| Qwen objective audit | `31d8f98:reports/qwen_objective_audit.md`, `runs/qwen_objective_audit/verify.log`. EXP-027 already backpropagated complete-group stabilized Pearson into actual Qwen LoRA.
