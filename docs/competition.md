# ArtEmotion-28 ST3 competition and provenance

The project pins organizer commit `cf7cc444cf56617f3b8417497c6930ad172c5c99`. The public ArtELingo-28 annotations live in `annotations/artelingo28_train_val.csv`. `split=train` supplies training votes and `split=val` supplies development gold. Images are under `images/<image_name>`. Use `painting` or `image_name` as the unique artwork key. The numeric `image_id` can identify multiple distinct artworks. [Pinned organizer README](https://github.com/artemotion-28/artemotion-28/blob/cf7cc444cf56617f3b8417497c6930ad172c5c99/README.md)

- Positive emotions are `amusement`, `awe`, `contentment`, and `excitement`. Negative emotions are `anger`, `disgust`, `fear`, and `sadness`. Exclude `other` and `something else` before requiring five votes for a painting-language pair. Each released annotation row represents one vote.
- Development input `phase_inputs/dev/st3_test.csv` provides `painting,language,image`. Model inputs are the image pixels and the target language. The submission is a ZIP containing `predictions.csv` at its root with `painting,language,p_positive`. This project validates exact coverage of the development input file.
- Keep the official evaluation phase separate. The organizers exclude English, Arabic and Chinese from evaluation-phase ST3 because the original ArtELingo release exposes their annotations for those paintings. The prohibition on using evaluation-painting annotations extends to every outside source. The published FAQ defers general guidance on LLMs and extra data to the competition platform and requires citations for external resources. This setup uses the official release and the CLIP checkpoint used by the organizers. [Rules and FAQ](https://github.com/artemotion-28/artemotion-28/blob/cf7cc444cf56617f3b8417497c6930ad172c5c99/README.md#competition-rules-and-terms) · [Codabench](https://www.codabench.org/competitions/18468/)
- Development submissions are visible to the team. Only the final evaluation submission counts for the ranking. Teams use one account and membership is fixed once evaluation begins. A system description paper is required for official ranking. [Organizer rules](https://github.com/artemotion-28/artemotion-28/blob/cf7cc444cf56617f3b8417497c6930ad172c5c99/README.md#competition-rules-and-terms)

## Scoring

- **Cultural Contrast** averages per-painting Pearson correlations between predicted and observed positive shares across supplied languages. A painting needs at least three scored languages and nonconstant gold shares. For eligible paintings, constant predictions score zero. Paintings contribute equally.
- **Log Loss** clips `q` to `[0.01, 0.99]` and computes `-(k*log2(q) + (n-k)*log2(1-q))/n` per pair. Average pair losses within each language and macro-average languages with at least 20 evaluation pairs. Report this in bits per annotator. The language cutoff applies to Log Loss in the published ST3 description. The starter notebook's all-pairs mean is reported separately for comparison.

Local scoring is reconstructed from the pinned README and starter kit. The public repository provides a starter scorer for Contrast and has no Codabench scorer source. Undefined aggregate metrics are represented by JSON `null`. [Evaluation specification](https://github.com/artemotion-28/artemotion-28/blob/cf7cc444cf56617f3b8417497c6930ad172c5c99/README.md#evaluation) · [Starter notebook](https://github.com/artemotion-28/artemotion-28/blob/cf7cc444cf56617f3b8417497c6930ad172c5c99/starter_kit/starter_kit.ipynb)

## Baseline and licensing

The baseline uses frozen CLIP ViT-B/32, RGB images, the checkpoint's CLIP preprocessing, batch size 32 and L2-normalized 512-dimensional image projections. Features concatenate the projection, a training-language one-hot vector and their outer product. The classifier is L2-regularized scikit-learn Logistic Regression with `C=0.3`, `lbfgs`, `max_iter=3000`, and default tolerance and intercept. Each pair contributes a positive example weighted by the positive vote count and a negative example weighted by the remaining votes. Predictions are rounded to six decimals. The sparse representation preserves the feature values and weighted objective while reducing memory use. The language prior uses the starter kit's unweighted mean training-pair share by language, with fallback `0.7`. [Pinned baseline source](https://github.com/artemotion-28/artemotion-28/blob/cf7cc444cf56617f3b8417497c6930ad172c5c99/baselines/st3/clip_language_lr.py) · [Pinned CLIP checkpoint](https://huggingface.co/openai/clip-vit-base-patch32/tree/3d74acf9a28c67741b2f4f2ea7635f0aaf6f0268)
