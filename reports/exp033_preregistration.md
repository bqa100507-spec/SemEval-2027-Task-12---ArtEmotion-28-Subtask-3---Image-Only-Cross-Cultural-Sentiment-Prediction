# EXP-033 · Preregistered representation comparison

The [approved strategy](exp033_representation_learning_strategy.md) describes the hypotheses, architecture and evidence from EXP-014, EXP-022 and EXP-030/031. This protocol uses the owner's A/B/C/D labels. [Frozen configuration](../configs/exp033.json)

| Condition | Region representation | Scientific comparison |
| --- | --- | --- |
| A | Four copies of the masked token mean plus the native pooled vector | Within-checkpoint global control |
| B | Four fixed Gaussian pooling regions plus the same native pooled vector | B−A tests access to spatial information |
| C | The same regions and native pooled vector, with trainable content attention | C−B tests learned aggregation |
| D | The same attention readout, with bottleneck adapters in the two final visual blocks | D−C tests anchored visual adaptation |

All use one pinned NaFlex-B/16 encoder, 256 patch slots, the same aspect-preserving RGB resizer and valid-token grid coordinates. Use the pinned Transformers slow `Siglip2ImageProcessor` explicitly. Both the prefix and token banks store FP32 tensors to avoid extra round-trip quantization. Padding cannot enter aggregation, attention keys or the drift term. All heads see 3,840 features, with the same full-rank centered language slopes and intercepts. The structurally redundant slots in A intentionally lack distinct region information. The equal head shape does not imply equal effective rank. The only additional learned parameters of C versus B are in the attention readout. The only additional trainable parameters of D versus C are **98,304** adapter weights. FP32 master weights, count-aware BCE, centered ridge and the patch anchor follow the strategy's formulas.

A/B/C/D use AdamW with fixed learning rates and the same seeded painting order, effective batch of 16 and number of optimizer steps. C and D share the complete first three epochs, including head, pooling, optimizer state and RNG. D enables its zero-output adapters after that fork. The same 16-painting schedule and epoch budget continue for both. Only the short technical preflight can select microbatch size (4/2/1) based on hardware headroom. The unscaled per-module gradient norms, clipping fraction, scaler skips, drift, time and parameter counts are logged each epoch. Clip norm is 5. Two consecutive epochs above 80% clipping or any epoch above 5% scaler skips block further training and keep diagnostics. Neither rule changes the recipe or triggers an automatic retry with new hyperparameters.

Use the exact five P2 folds and a seeded painting-disjoint 80/20 split inside fitting. Select a common epoch from 6, 9 and 12 using only C/D inner predictions. Among epochs within +0.005 bits of each arm's own minimum inner Macro Log Loss, maximize mean inner Contrast, then minimize mean Log Loss and prefer earlier epochs. If no epoch qualifies, minimize mean loss first. Refit all conditions from the specified initialization on full outer fitting under the chosen common schedule. Outer probabilities are scored only after all five prediction seals exist. D's adapted tokens stay fold-local. The matched fixed-pooling probe fits B's readout from scratch on D tokens for that fold and is diagnostic only.

Report standalone A/B/C/D and one fixed fusion replacing only the SigLIP2 component of archived EXP-032 ridge. Reproduce the three original ridge component predictions and check their nested six-decimal blend against the archived ridge OOF before running. Keep CLIP-B/L predictions constant for all conditions, with fusion weights 0.25/0.25/0.50. Compare the fixed fusion against frozen E50+L and ridge on the same keys. Score pooled and per fold, calculate rank/concordance and calibration, and resample paired eligible paintings 10,000 times. Report fitting-language support slices. P2 evidence is exploratory.

D requires +0.001 Contrast over C and +0.002 over both historical references. Each contrast also needs a strictly positive lower bootstrap endpoint, at least three positive folds and a Macro Log Loss change no worse than +0.005 bits. The fixed C condition may qualify on the same reference gates, with +0.001 vs B and a positive paired interval and gain vs A. A hardware or numerical block stops the four-condition run. The implementation does not initiate a separate backup study. Production, confirmation and Development remain outside this run.

The notebook defaults to disabled. One owner authorization covers pretrained CUDA feasibility, local verification of the optimizer/scaler/RNG canary, and all five folds if those checks pass. The same session saves sealed checkpoints each epoch and exports a verified archive on completion or handled failure. A previous archive can be attached for optional resume. A lost runtime may lose everything saved only in that runtime. All scientific settings remain as specified above.
