# EXP-030 · Full-scale native Qwen 7B

One research run tests whether a native-vision Qwen2.5-VL-7B, trained on all 1,068 fitting paintings of P2 fold 3, can improve Cultural Contrast over E50+L. Prior short 3B runs do not settle this question. This fold has been used before, and its 267 held-out paintings select the best epoch. Treat the resulting scores as exploratory.

## Frozen recipe

- Official Qwen2.5-VL-7B-Instruct revision cc594898137f460bfe9f0759e9844b3ce807cfb5. The published model card declares Apache-2.0. The worker checks the exact card, tokenizer and processor files and all five weight shard hashes. Competition eligibility is separate. [Pinned model card and license declaration](https://huggingface.co/Qwen/Qwen2.5-VL-7B-Instruct/tree/cc594898137f460bfe9f0759e9844b3ce807cfb5)
- The native frozen BF16 vision tower produces the real image tokens and grid from the official processor (100,352–200,704 pixels). An in-memory bounded cache reuses its outputs. The decoder uses the native multimodal rotary positions and final valid token. NF4 double-quantized decoder weights stay frozen. BF16 compute and a FP32 LayerNorm/linear eight-class head train alongside rank-16, alpha-32 Q/V LoRA in all 28 decoder blocks. The model sees the image and target language. E50+L is used only for scoring comparisons.
- Training minimizes eight-way CE + 0.5 × binary BCE, both summed over original votes and divided by the total vote count per accumulated update. Positive probability sums the first four emotion probabilities. Use 2 pairs per microbatch and accumulate up to 16, with checkpointing, AdamW (head LR 0.001, adapter LR 0.0001, weight decay 0.01), global norm cap 1, seed 2030, deterministic math SDPA and fixed learning rates. The final short accumulation window contributes all its votes.
- Use 10,879 fitting and 2,721 held-out pairs. Reconstruct all eight counts from the pinned public annotation file, skipping out-of-scope paintings and rows before examining their emotion values. Verify counts against the original P2 binary totals and exact fold keys. The scorer sees only held-out keys and counts. The frozen reference is 0.433536 Contrast and 0.713192 bits Macro Log Loss. The sealed 236-painting set is outside the run.

## One Colab run

1. Open [EXP030 Colab](../notebooks/EXP030_Colab.ipynb) and choose an A100 if available. L4 is admitted only after the same real pretrained feasibility check passes. Keep the original TASK-034 exp023_handoff.zip in MyDrive, and ensure local runtime storage can hold the roughly 16.6 GB checkpoint plus the environment and staged paintings.
2. Set AUTHORIZE_EXPERIMENT to True and choose Run all. Default budget is 8 hours from the start of setup, up to 12 hours by explicit configuration. Colab can reclaim the GPU earlier. A single automatic feasibility phase checks the native path, BF16/NF4, a capped-size image grid with long prompts, finite gradients, adapter updates and at least 1 GiB remaining VRAM. It then restores the starting weights and RNG before scientific training. It does not change model or batch size on failure.
3. Follow the printed pair throughput and train-only estimate. The first estimate can include cold-cache cost and excludes held-out evaluation and checkpoint publication. The worker stops at six epochs, a resource limit or a numerical/technical failure. No patience rule. Highest measured Cultural Contrast selects the checkpoint, with earliest epoch breaking an exact tie. Macro Log Loss evaluates probability quality separately.
4. Read results.json and outputs.zip under MyDrive/exp030/attempts/. Verified epoch directories under MyDrive/exp030/checkpoints/ contain the head, adapters, optimizer and RNG states plus validation predictions and metrics. Learning rates are constant, so there is no scheduler state. Rerun the same notebook on the same GPU/runtime profile and checkpoint path to continue. A partially completed epoch is repeated from the last verified boundary. If the previous VM was killed and left .active behind, confirm that it stopped and remove that marker before restarting. Different checkpoint identities or corrupt seals stop recovery. The archive contains the small report and logs; large checkpoint files remain in their own Drive directories.

Read the learning curve against the reference and the latest validated epoch. Falling fitting loss with rising held-out BCE suggests overfitting. Improving held-out Contrast at the budget boundary leaves the trajectory unresolved. A flat short curve cannot distinguish underfitting from optimization limits by itself.
