# EXP-029 — CLIP-guided Qwen pilot

This research-only prototype adds four soft visual tokens to the pinned Qwen2.5-VL-3B decoder. Unit-normalized CLIP-L and SigLIP2-Base vectors form a unit-normalized 1,536-vector. A 1536 → 256 → 4 × 2048 GELU projector produces the prefix. The scalar head reads the final valid decoder token after a target-language instruction and outputs sigmoid(logit(p_E50L) + 0.1 × residual). The zero-initialized head starts at baseline. The native Qwen vision tower and vocabulary projection are bypassed.

Transformers 4.51.3 accepts direct embeddings with a binary padding mask and explicit [3, batch, sequence] rotary positions. The learned prefix tokens have no image grid and occupy successive sequence positions on the same diagonal of all three rotary axes as text. CPU tests exercise the pinned decoder class with small random weights, including text-only parity and padded versus unpadded readout. The notebook separately checks the pretrained NF4 CUDA path. [Pinned decoder source](https://github.com/huggingface/transformers/blob/v4.51.3/src/transformers/models/qwen2_5_vl/modeling_qwen2_5_vl.py) · [Pinned Qwen checkpoint](https://huggingface.co/Qwen/Qwen2.5-VL-3B-Instruct/tree/66285546d2b821cf421d4f5eb2576359d3770cd3)

## Fixed pilot

- The exact EXP-026 pilot has 192 inner-training paintings / 1,956 pairs and 48 inner-validation paintings / 493 pairs. Only their vote counts are parsed for learning or evaluation. Four painting-grouped splits produce training E50+L inputs from freshly fitted heads that exclude each predicted painting. A separate three-head fit on all 192 training paintings predicts validation. Both use the existing vote-weighted LR objective, C=0.3, and nested six-decimal blending. The training residuals see baseline heads fitted on 144 paintings per cross-fit split, while validation sees baseline heads fitted on 192.
- Compare the matched baseline, projector and scalar head with frozen NF4 Qwen, and the same projector and head with rank-8/alpha-16 LoRA on all 36 decoder Q/V pairs. Train each for at most two epochs with AdamW, seed 2027, 16 pairs per batch, count-weighted BCE, LR 0.001 for projector/head and 0.0001 for LoRA, gradient norm cap 1 and weight decay 0.01. The earliest minimum validation BCE selects each checkpoint. The zero head delays upstream gradient until after its first update. A disposable six-painting, one-step diagnostic uses a nonzero probe head to check upstream gradients and output sensitivity, then restores pristine adapters.
- The shuffle swaps visual prefixes across entire validation paintings while preserving target language and original E50+L probabilities. Report the primary Contrast, eligible-language Macro Log Loss, BCE curves, GPU timing and peak VRAM. Inspect gains against baseline and projector-only alongside the shuffle and Log Loss. The same validation set selects checkpoints, so scores are exploratory. No automatic progression, outer-fold evaluation, confirmation, Development, or submission. Qwen's Research License applies and competition eligibility remains unresolved. E50+L stays in production.
